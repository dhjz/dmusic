## alist音乐播放器music player
### 开发语言
- 前端: vue3
```shell
yarn install
yarn build:h5
```
### 功能介绍
- alist音乐播放器, 支持播放指定alist仓库的音乐
- 支持自动扫描多层级目录
- 支持播放控制, 上一曲, 下一曲, 暂停/播放
- 支持歌词显示, 同目录和音乐文件同名的歌词文件就行
- 支持函hbuilder打包成app运行
- 支持歌手搜索项, 自定义searc.json文件
```json
{
	"singers": ["周杰伦","刘德华","张学友","林俊杰","陈奕迅","beyond","邓紫棋","王杰","王力宏","薛之谦","飞儿乐团","周深","谭咏麟","其他"]
}
```
